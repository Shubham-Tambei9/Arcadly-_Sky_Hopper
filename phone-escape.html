About the game

You are holding a phone that is not yours. Its messages, photographs, browser history and notes all belong to somebody else — and somewhere in them is the code that gets you out before the timer runs down.

Seventy-one cases across five sets, from a first afternoon to four-lock expert runs. Every one is a real chain of deduction: a name on a contact card, a frame missing from a photo sequence, a page somebody visited twice. Nothing is guesswork, and a hint is always there if you want one.

Deduction, not guessing.

Every code is earned

Each answer is derived from evidence actually on the phone. Cases are built answer-first, so a solution always exists and is always reachable.

The clock bites

A wrong answer costs thirty seconds. Three wrong on one lock starts a sixty-second device wipe. Guessing is a decision with a price.

Nothing leaves the phone

No ads, no analytics, no accounts. The app asks for no Android permissions at all and has no networking code in it.
